# Project Studio

This project was updated as a Week 5 milestone deliverable for a professional presentation-ready Astro website.

## Included work

- Updated branding and homepage messaging
- Added a dedicated Week 5 slides page
- Replaced placeholder content with project-focused overview text
- Updated navigation and footer content
- Kept the site structure ready for future project expansion

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Key pages

- `/` — project homepage
- `/week-5-slides` — slide deck overview
- `/about` — project summary
- `/blog` — starter blog section
